目录以「每个 IP 一个子目录」的方式组织，各子目录遵循统一的 Anlogic IpTool 生成结构：顶层为 `<IP>.v` 包装模块，内部通过参数化实例化 `RTL/` 下的具体实现（如 `ph1p_ddrmc_wrapper_MIS_DDR.v`、`axi_matrix_wrapper_AXIfull_Matrix.v`、`al_axi_clock_converter_AXI_Clock_Converter_ddr.v`、`ph1p_phy_pll_wrapper_sysPLL.v`），同时附带 `Design.xml` / `DesignConfiguration.xml` / `.params_*.txt` / `.ports_*.txt` 等元数据供工具链使用。

- MIS_DDR：最复杂的 IP，顶层 `MIS_DDR.v` 仅做端口透传与参数配置，真正逻辑在 `src/rtl/` 下按功能分目录（`mc/` 内存控制器、`phy/` PHY 层含 APB 桥、命令解码、读写相位控制、MDL 校准、fast_init 等、`clk/` PLL、`init/` DRAM 初始化、`timing/ddr2/` 时序参数头文件、`misc/` 同步复位等），并通过 `sim/fileset/fileset_mis.f` 提供仿真文件列表。
- AXI_Clock_Converter_ddr：封装 `al_axi_clock_converter`，在 us/ds 两个时钟域之间做 AXI 协议转换，通过 US_ACLK_RATIO/DS_ACLK_RATIO 配置频率比。
- AXI_lite_Matrix / AXIfull_Matrix：基于 `axi_matrix_wrapper` 的 AXI 交叉开关，分别面向 Lite 与 Full 协议，通过 AL_US_NUM/AL_DS_NUM/AL_CONNECTIVITY_MODE 等参数配置主从数量与路由规则。
- sysPLL：系统时钟 PLL，输出 C0/C1/C2 三路时钟，经 BUFG 缓冲后对外。
- axis_dmadat_fifo / axis_mac_rxfifo：基于同一 `axis_data_fifo_pkg.vh` 包的 AXIS 数据 FIFO，包体被 `pragma protect` 加密，仅暴露接口。

依赖方向单向向外：顶层包装模块 → 内部 wrapper → 具体 RTL；各 IP 之间无相互引用，由上层工程组合。
