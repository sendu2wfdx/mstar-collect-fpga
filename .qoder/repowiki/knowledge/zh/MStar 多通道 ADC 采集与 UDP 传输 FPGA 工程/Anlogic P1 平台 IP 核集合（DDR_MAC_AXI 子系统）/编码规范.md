- 每个 IP 子目录包含顶层 `<IP>.v` 包装模块，仅声明端口并通过 `#()` 参数实例化内部 `RTL/` 下的具体实现模块，实现接口与实现的解耦。
- 所有 IP 顶部带有统一格式的版权注释块，包含 Copyright (Anlogic Inc.)、Gen time、IpTool version、App version、Ip Version 等元信息。
- RTL 代码通过 `include/define.v` 或 `include/*.vh` 集中放置宏定义，顶层包装模块与内部实现均从该路径引入公共常量。
- IP 元数据（端口宽度、参数默认值、端口名）以 `.params_<IP>.txt`、`.m_params_<IP>.txt`、`.ports_<IP>.txt` 三个文件形式与 `.v` 文件并列存放，供 IpTool 解析。
- 需要保密的核心算法（如 AXIS FIFO 包）使用 `pragma protect` 加密，仅暴露接口头文件给调用方。
