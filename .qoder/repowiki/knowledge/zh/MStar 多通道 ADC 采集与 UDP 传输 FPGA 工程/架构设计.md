根目录以 `tand_udp.al`（Tang Dynasty IDE 工程文件）为唯一入口，将两个子模块按职责分层装配：
- `hdl/` 下的 `mstar_udp_top.v` 作为综合与布局布线的顶层（`TOP_MODULE=mstar_udp_top`），串联 ad_driver、collect、axi_dma、udpip、sync 等 RTL 子模块。
- `al_ip/` 下的 Anlogic P1 IP 核（MIS_DDR、AXI Matrix、sysPLL、FIFO 等）通过 `<IP_FILE>` 节点注册到同一 `design_1` FileSet，被顶层实例化提供 DDR 缓存、时钟域转换与 AXI 互联。
- 约束文件（ADC 引脚 `.adc`、SDC 时序 `.sdc`）归入 `constraint_1` FileSet，由 syn_1 → phy_1 两条 Run 顺序执行，物理设计策略启用 bin 输出与时序优化。
- 以太网桥接 IP `hdl/udpip/mstar_ethernet_bridge.ipr.v` 以加密网表形式参与综合，不暴露源码但通过 AXI 总线与采集/UDP 逻辑交互。
两个子模块之间无共享代码，仅通过顶层实例化与 IP 接口契约耦合，由 `tand_udp.al` 的 CompileOrder 字段隐式规定依赖顺序。
